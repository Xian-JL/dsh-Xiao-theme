# dsh-xiao-theme 1.1.3

- 修复窗口切换后残留绿色边框、紫色弧线和方块：作者 `display: block` 曾覆盖风痕池的 `hidden` 状态。现在隐藏节点明确不绘制，动画子图形默认透明，取消动画不会重新显示静态图形。
- 生日贺图主立绘采用 32 px 圆角裁切，设置预览采用 20 px 圆角。
- 保留全部点击动效和三倍表现强度，动画池可正常复用。

验证：`npm run verify` 通过，共 300 条断言。实际 Chromium 浏览器对比上一版样式与本版，复现旧版取消动画后的残留图形，并确认新版本立即取消后所有节点不绘制、再次播放后正常结束。

素材来源与处理说明见 `THIRD_PARTY_ASSETS.md`。本次发布未新增第三方图片。
